## Description

The plots below are generated by the docs build itself (see `make docs` /
`tests/docs/`), by exporting real `cicwave` sessions against a small
synthetic dataset (`tests/docs/gen_testdata.py`). They're not
hand-drawn screenshots — every push to `main` regenerates them from a
live run of `cicwave --export`, so they never drift from what the tool
actually renders.

There is example test data and session files in `tests/docs`. Navigate
to that directory to reproduce these locally.
